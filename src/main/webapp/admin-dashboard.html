Roles & Permissions Governance

Role-Based Access Control (RBAC). Explicit permission checks enforced strictly in Java backend.

🛡️

Special Whistleblower Permission: VIEW_PROTECTED_IDENTITY

"Do not give every admin automatic access to protected student identity. Use explicit permissions."

When students file protected complaints, their real identities are cryptographically quarantined in MySQL protected_complaint_identity. Even with the ADMIN role, administrators are strictly prohibited from viewing whistleblower names, contacts, and room numbers unless the explicit permission VIEW_PROTECTED_IDENTITY is granted to their individual user account.
